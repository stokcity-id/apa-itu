# MENGENAL STOKCITY ID: APLIKASI, WEB, DEMO, LOGIN, DAN STATUS OJK

[**Stokcity**](https://stokcity.net/) adalah platform digital yang digunakan untuk mempelajari pasar dan memahami berbagai instrumen melalui satu akun. Layanan ini memiliki lebih dari 3,5 juta pengguna di lebih dari 130 negara, termasuk Indonesia. Platform dapat diakses melalui web maupun aplikasi untuk perangkat mobile.

## STOKCITY ID DAN VERSI WEB

Pengguna [**Stokcity**](https://stokcity.net/) ID dapat mengakses platform melalui browser. Versi web tidak memerlukan aplikasi komputer terpisah dan dapat dibuka dari perangkat desktop maupun laptop.

Untuk membantu analisis, tersedia lebih dari 30 alat. Antarmuka dirancang agar fungsi utama dapat diakses dalam satu platform tanpa perlu berpindah antara beberapa layanan.

## LOGIN DAN DEMO

Pengguna dapat masuk ke akun [**Stokcity**](https://stokcity.net/) menggunakan data akun atau metode login yang tersedia. Stokcity juga menyediakan mode demo dengan saldo virtual sebesar USD 10.000.

Saldo demo tidak memiliki nilai nyata dan tidak dapat ditarik. Pengguna dapat mengatur ulang saldo tersebut untuk kembali mencoba berbagai fungsi platform.

Mode demo dapat digunakan untuk mempelajari:

- susunan antarmuka
- instrumen yang tersedia
- alat analisis
- navigasi akun
- fungsi utama platform

## APLIKASI STOKCITY

Aplikasi tersedia untuk perangkat Android dan iOS. Pengguna Android dapat memperoleh aplikasi melalui Google Play atau APK resmi, sementara pengguna iPhone dan iPad dapat mengunduhnya melalui App Store.

## PARAMETER AKUN DAN DUKUNGAN

[**Stokcity**](https://stokcity.net/) menetapkan beberapa batas minimum dalam penggunaan layanan. Nilai minimum transaksi adalah USD 1, sedangkan deposit minimum dan penarikan minimum masing-masing sebesar USD 10.

Dukungan pengguna tersedia 24/7 melalui chat dan email, serta melalui bagian FAQ. Platform juga menyediakan materi edukasi untuk membantu pengguna memahami berbagai fungsi serta informasi pasar.

## APAKAH STOKCITY AMAN?

[**Stokcity**](https://stokcity.net/) menggunakan SSL 256-bit, autentikasi dua faktor, serta pemisahan dana. Pengguna juga dapat menjaga keamanan akun dengan menggunakan kata sandi yang kuat dan tidak membagikan data login.

## APAKAH STOKCITY LEGAL DI INDONESIA DAN BAGAIMANA STATUSNYA DI OJK?

[**Stokcity**](https://stokcity.net/) dioperasikan oleh VERTE SECURITIES LIMITED dan memiliki lisensi Vanuatu Financial Services Commission (VFSC), nomor 700726.

Stokcity tidak berada di bawah pengawasan OJK di Indonesia. Lisensi VFSC dan otorisasi OJK merupakan dua bentuk perizinan yang berbeda.
